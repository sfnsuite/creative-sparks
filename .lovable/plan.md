
## السياق المهم

المشروع دابا فارغ (بلانك تومبلات)، فالتحليل اللي عطيتك قبل كان غالط — خاصني نبنيو كلشي من الصفر. هادي خطة كاملة.

## الفكرة الأساسية

3 حاجات كنبنيوهم مع بعض:

1. **موقع للخياط** فيه 3 أنواع د الكلاينت: شراء جاهز / خياطة موديل خاص / إنتاج بالجملة (B2B).
2. **لوحة أدمين ساهلة بحال Instagram** — الخياط كيدير صورة + وصف + الثمن، صافي.
3. **نظام "كارتات إشهار"** — كل كارت عندو **لينك ثابت** كايتحط ف Instagram Ads، والمنتج داخل الكارت قابل للتبديل بلا ما يتكسر الإشهار.

## الصفحات (Public)

- `/` — الصفحة الرئيسية: hero + 3 مسارات (اشري جاهز / صمم موديلك / إنتاج بالجملة).
- `/shop` — كتالوغ المنتجات الجاهزة (فلترة بالنوع/الحجم/الثمن).
- `/product/$slug` — تفاصيل منتج.
- `/custom` — فورم "صمم موديلك": صورة مرجعية + قياسات + ملاحظات → كايوصل للأدمين.
- `/wholesale` — فورم B2B للتجار.
- `/c/$cardId` — **صفحة الكارت الإشهاري** (هادي المهمة، شرح تحت).
- `/auth` — تسجيل دخول (للأدمين فقط دابا).

## نظام الكارتات الإشهارية (الجزء الذكي)

كل "كارت" هو URL ثابت (`/c/abc123`) كايتحط ف إعلان Instagram. الخياط ف الأدمين كيقدر:

- يبدل المنتج الرئيسي داخل الكارت بلا ما يتبدل اللينك.
- يزيد **منتجات مصاحبة** (مثلا: قميص رئيسي + سروال + جاكيط مقترحين تحت).
- يشوف كم واحد ضغط على الكارت (analytics بسيطة).

```text
Instagram Ad → /c/abc123 → [منتج رئيسي] + [3 منتجات مقترحة] + CTA
                              ↑
              الأدمين كيبدلو من غير ما يمس اللينك
```

## لوحة الأدمين (Instagram-Style)

مسار `/_authenticated/admin/*`. التصميم كيحاكي Instagram/Facebook posting:

- **إضافة منتج** = بوطون كبير `+` → يختار صور من التيليفون (drag & drop أو زر) → عنوان + وصف + ثمن + نوع → **نشر**. صافي.
- **Grid د المنتجات** بحال feed Instagram — كليك على المنتج = تعديل مباشر.
- **الكارتات الإشهارية**: تاب فيه ليستة الكارتات، كل كارت كيبين المنتج الحالي + بوطون "بدّل المنتج" (dropdown بالمنتجات).
- **الطلبات**: ليستة د اللي طلبو (شراء / تصميم خاص / جملة) مع status (جديد / قيد المعالجة / مكمل).
- كلشي بالعربية/الدارجة، بلا مصطلحات تقنية.

## المخطط التقني (للمرجع)

قاعدة البيانات (Supabase):

- `products` (id, slug, title, description, price, category, images[], sizes[], stock, active)
- `promo_cards` (id ثابت قصير, active_product_id → products, companion_product_ids[], headline, click_count)
- `custom_orders` (design brief للخياطة الخاصة)
- `wholesale_leads` (طلبات B2B)
- `orders` (طلبات الشراء المباشر)
- `user_roles` (لحماية الأدمين — نمط has_role الآمن)
- Storage bucket `product-images` لصور المنتجات

Auth: Email + كلمة السر للأدمين. الزبون العادي ماكيحتاجش حساب باش يطلب.

Stack: TanStack Start (موجود) + Lovable Cloud (Supabase) + shadcn/ui + Tailwind.

## قابلية التخصيص كتومبلات

باش نقدرو نعاودو نستعملوه لكلاينتات أخرين:

- **ملف إعدادات المتجر** (`src/config/shop.ts`): اسم المحل، الألوان، اللوغو، أنواع الخدمات (الخياط عندو 3، كلاينت آخر يمكن عندو 2).
- **الألوان design tokens** ف `src/styles.css` — بدلها = بدل الهوية البصرية كاملة.
- المسارات (`/custom`, `/wholesale`) قابلة للتشغيل/الإطفاء من config.

## خطوات التنفيذ

1. تفعيل Lovable Cloud + إنشاء الجداول والـ RLS policies والـ storage bucket.
2. Auth + role الأدمين + gate على `/_authenticated/admin`.
3. الصفحات العامة: `/`, `/shop`, `/product/$slug` بتصميم أنيق للخياطة.
4. لوحة الأدمين: إضافة/تعديل المنتجات بواجهة Instagram-like.
5. نظام الكارتات الإشهارية `/c/$cardId` + إدارتها ف الأدمين.
6. فورمات `/custom` و `/wholesale` + تاب الطلبات ف الأدمين.
7. ملف الـ config للتومبلات + توثيق قصير كيفاش تبدل ديال كلاينت جديد.
8. SEO لكل صفحة (title/description/og) + og:image من صور المنتجات.

## أسئلة قبل ما نبدا

- **الألوان والهوية**: عندك لوغو ولا ألوان معينة للمحل؟ ولا نقترح ليك ديركسيون؟
- **العملة واللغة**: درهم مغربي؟ الموقع بالعربية فقط ولا عربية + فرنسية؟
- **الدفع**: دابا نخليو الطلب "اتصل بينا / واتساب"، ولا بغيتي دفع أونلاين (Stripe/CMI) من دابا؟
- **الشحن**: توصيل داخل مدينة وحدة، ولا كامل المغرب؟

جاوبني على هاد الأسئلة ونبدا التنفيذ.
